- `@audio/encode-mp3` 1.2.2, copyright its contributors, MIT License.
- `wasm-media-encoders` 0.7.0, copyright its contributors, MIT License. It contains the bundled LAME encoder build used by `@audio/encode-mp3`.

The installed package license texts are included in the npm dependency tree and reproduced in source distributions through `package-lock.json`.

The test fixture `tests/fixtures/synthetic-tone-440hz.mp3` is an original 440 Hz synthetic tone generated by `scripts/create-test-mp3.mjs` with the bundled encoder. It contains no third-party recording.
